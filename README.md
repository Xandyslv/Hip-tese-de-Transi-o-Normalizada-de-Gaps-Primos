# Hip-tese-de-Transi-o-Normalizada-de-Gaps-Primos
A HTNGP propõe que certas lacunas entre números primos consecutivos não se sucedem com a mesma frequência que seria esperada a partir apenas de suas frequências individuais. Essa preferência ou supressão pode ser medida pela razão normalizada (R{ab}(x)), e a hipótese propõe que, para transições admissíveis.
